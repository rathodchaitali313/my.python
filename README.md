🎮 Hangman Game in Python

A simple, interactive Hangman word-guessing game built with Python 

🎯 About the Project

The computer randomly selects a word from a predefined list, and the player tries to guess it one letter at a time.

The game displays blanks for unguessed letters, reveals correct guesses, and tracks the player's remaining lives. The player wins by guessing the complete word before running out of lives.

✨ Features

- Random word selection
- Interactive letter guessing
- Hidden-word display that updates with correct guesses
- Tracking of correctly guessed letters
- Limited lives and Hangman ASCII art stages
- Win and lose conditions

▶️ How to Run the Game

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

python hangman.py

5. Enter a letter when prompted and try to guess the hidden word.

Note: Keep "hangman.py" and "hangman_art.py" in the same folder so the import works correctly.
